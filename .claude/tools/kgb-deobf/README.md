# Разбор PBO с обфускацией KGB (проверено 2026-11-17 на BRDK_GoldRush)

Признаки: классы `KGB_<GUID>` в CfgPatches/CfgMods, папки и файлы с мусорными именами (`COM1.xxx.c%b`, иероглифы),
сотни `.c`, где почти всё — `#ifdef СЛУЧАЙНОЕ /* слово */ #else /* слово */ #endif`. Mikero такой PBO не открывает
(`DePbo: Pbo unknown header type`).

1. `python -I pbox.py <файл.pbo> <папка>` — своя распаковка (LZSS «Cprs», мусорные символы имён экранируются).
2. Найти **все** `config.bin` (в корне и во вложенных папках) и перевести в текст: `DeRap.exe -P <config.bin>`.
   Вложенные конфиги подменяют мод цепочкой: каждый `delete` предыдущий класс CfgMods и задаёт свою папку
   `worldScriptModule`. Настоящая папка скриптов — у последнего (без `delete` на себя) класса. Классы с `defines[]`
   не удаляются: активны defines **всех** конфигов (у серверной части добавляются ещё и клиентские).
3. `python -I deobf.py <настоящая папка скриптов> <вывод> <все config.cpp>` — вычисляет директивы, выкидывает
   комментарии (в них приманки), настоящие defines движка (`SERVER`, `DIAG_DEVELOPER`…) оставляет.
   Все остальные папки и большие файлы — приманки, их корневой `#ifdef` не определён.
4. Длинные имена `<Мод>_<32 символа>` заменить короткими для чтения.

Внимание: в восстановленном коде BRDK была проверка лицензии и отправка IP/имени сервера в Discord автора.
Токены вебхуков не сохранять в репозиторий.
