## Оси и соглашения

- MLOD: y вверх, нос в −z, +x — левый борт (водитель). Blender (рендер, колесо): (x, z, y) — нос в −Y.
- MLOD → Blender: порядок вершин не менять, нормали со знаком минус; UV: v → 1 − v.
- Прокси: py3d `get_proxies()` даёт сырую рамку (x, y, z); точка детали c → anchor + c0·(−x) + c1·z + c2·y.
- Колесо: ось вращения = локальная x, внешняя сторона (диск, бедлок) = +x. У левых колёс локальная +x смотрит
  наружу, у правых прокси повёрнут на 180°.

## Подъём (er_build.py)

- Колёса ALEX: центр перед 0.446, зад 0.394, видимый радиус 0.366 (в конфиге 0.33), земля ~0.02.
- Кости `susp_damper → susp_hub → wheel` (перед) и `susp_axle_2_dummy → susp_axle_2 → susp_damper_X_2 → wheel`
  (зад) опускаются на dc; передние стойки тянутся (верх на месте). Неподвижная ходовая (`hodovka`, `hodovka_anm`):
  рычаги спереди наклоняются по вылету, задний мост опускается.
- **`wheel_*_damper_land` в Geometry (1e13)** — коробки вокруг колёс по 150 кг: едут с колесом (dc).
  В LandContact (2e15) — 4 точки на земле: едут с землёй (drop). Не путать.
- Земля: `pos_driver`, `pos_codriver` и их `_dir`, LandContact — вниз на drop = dc + (R − 0.366).

## Детали этапа 2 (er_parts.py)

- Порядок: `er_build.py` → `er_wheel.py` → `er_parts.py` → `er_render.py` по `work/<вариант>/final/`.
- Цвета деталей черновые (`#(argb,...)`), в поле rvmat — подсказка рендеру `metal`/`emit` (не путь!).
  Перед сборкой мода заменить на настоящие текстуры и rvmat (этап 5).
- Выделения деталей: `er_flares`, `er_lightbar`, `er_net`, `er_vent`, `er_plates`, `er_rivets`. В `dmgzone_*` их не класть:

- Сетки окон дверей — в моделях дверей (едут с дверью, не мешают посадке); задние форточки — в кузове, и в видах
  из кабины 1100/1201.
- Geometry / Fire / View Geometry для новых деталей ещё не добавлены — на этапе мода (расширители, люстра).
- Запаски нет: `er_parts.py` убирает прокси `interceptor_wheel.005`, выделения `wheel_spare_1`, `lancuch` (цепь)
  и компонент запаски в Fire/View Geometry.

## Навесные (er_attach.py)

- Порядок: `er_build.py` → `er_wheel.py` → `er_parts.py` → `er_attach.py` → `er_render.py` по `work/<вариант>/full/`.
  Ночной рендер: `--night` (видно свечение). Свои ракурсы: `--shots="имя:cx,cy,cz:tx,ty,tz:объектив;..."`
  (оси Blender), вид из кабины — `--lod=1100`, глаз водителя ~ (0.43, 0.32, 1.22); срез крыши `--clipz=1.40`,
  без дверей `--skip=doors`.
- Модели: `full/proxy/vb_er_tank.p3d`, `vb_er_pipes_l.p3d`, `vb_er_pipes_r.p3d`, `vb_er_pipes_engine.p3d`. Начало модели —
  центр детали; прокси в машине `\vb_echorunner\proxy\<имя>` (бак .001 левый, .002 правый) с тождественной рамкой
  (в «сырых» осях py3d: ((-1,0,0),(0,0,1),(0,1,0))), в LOD 1–4 и 1100/1201.
- У навесных есть Geometry (выпуклые коробки/призма, масса, `autocenter=0`), Fire и View Geometry.
- Светящееся — выделение `neon` (трубы, бандажи бака, окошко коллектора) — под hiddenSelection на этапе мода.
- Трассы труб — точки в `side_route()` / `engine_route()` (оси Blender, левый борт; правый зеркально). Пороги ниже низа
  двери (z 0.47), чтобы открытая дверь не задевала. Задний подъём перед аркой, через край кузова к боку бака.
  Передний подъём между крылом и дверью (решётка крыла сдвинута вперёд), по проёму у лобового к нагнетателю.
- Вторая труба идёт параллельно (`offset_path`), на подъёмах — гофро-рукав.

## Салон (er_interior.py)

- Замеры салона и прокси, которым нельзя мешать (оружие, рюкзак, гранаты, голова водителя), — в шапке er_interior.py.
- У ALEX есть поперечины каркаса под крышей (над лобовым и у средних стоек); остальное (боковые дуги, стойки
  главной дуги, диагональ, поперечина ремней, передние трубы вдоль стоек лобового) — наше, выделение `er_cage`.
- Светящееся в салоне — выделение `neon` (как у навесных): полосы на потолке, под торпедо, на дверях, экран,
  «молния» в колбе.
- Места ALEX под бочки (`55galdrum`) убраны в er_parts.py вместе с запаской.
- Правило обзора: светящееся не класть в поле зрения водителя над капотом (ночью слепит) — трубопровод мотора
  светится только на подъёме у крыла (`glow_to=0.40`).

## Текстуры (этап 5)

- Порядок: `er_build.py` (свои пути + копия данных ALEX) → `er_tex_parts.py` → `er_wheel/er_parts/er_attach` →
  `er_tex_bake.py` → `er_tex_paint.py` → рендер. Системный Python без numpy — генераторы текстур через Blender.
- Пути: модель ссылается на `vb_echorunner\data\...` (er_build переносит с `interceptor_byalex\data\...`);
  текстуры ALEX копируются под теми же именами, только если файла ещё нет (перекрашенные не затираются);
  бинарные rvmat ALEX пересобираются текстом с нашими путями стадий. Номер из чужого mod_tuning -> er_steel_rust.
- Детали: материалы `vb_echorunner\data\parts\er_<имя>` (er_geom.COL, er_wheel.MATS), UV коробочные в метрах
  (без % 1.0 — иначе разрывы на стыках граней), экран — своя рамка UV (`Part.uvframe`).
- Неон: `er_neon.rvmat` (emmisive {1,1,1,22}, как ванильные фонари) и `er_neon_off.rvmat` (тёмное стекло) — скрипт
  меняет материал выделения `neon`. Экран — `er_screen.rvmat` (emmisive {1,1,1,10}).
- Перекраска кузова (er_tex_paint): по 3D-положению текселя — без швов на стыках островов, зеркальные половины
  одинаковы (|x|). Слои: тёмная сталь из яркости ALEX, ржавчина ALEX сохраняется, своя ржавчина + потёки (только
  на вертикалях), швы листов с двумя рядами заклёпок (борта: шаг 0.5 м и z 0.52/0.80; верх: шаг 0.55 м и |x| 0.40),
  царапины; эмблема на задней решётке размыта. Мотор: таблички на клапанных крышках размыты.
- PNG-исходники — в `work/` (не в мод). `work/` ~0.5 ГБ — в git не класть.
