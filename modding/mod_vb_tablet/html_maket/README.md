# HTML-макет КПК

Открыть `index.html` в браузере, сервер не нужен. Справа оранжевая вкладка «Макет»: экраны, модули, батарея, роль.

Клавиши как в игре: P открывает, TAB листает вкладки, Esc закрывает. На карте ЛКМ двигает, колесо масштабирует, ПКМ ставит метку. В чате ПКМ по сообщению открывает меню.

Адрес задаёт стартовое состояние: `index.html?t=3&r=1&m=gps,map`. `t` вкладка (0 профиль, 1 карта, 2 связь, 3 группировка, 4 новости, 5 админ, 6 персонаж), `r` роль (3 лидер, 2 заместитель, 1 боец, 0 нет), `m` вставленные модули, `s` экран (`auth`, `trophy`, `hud`, `boot`), `noanim=1` без анимаций.

## Как устроен

Сетка 1920x1080, координаты те же, что в исходниках. Хелперы `js/draw.js` повторяют `INT_UIF_Draw`, `INT_UIF_Surface` и `INT_PDA_Look`, поэтому правка переносится в Enforce-код почти один к одному.

| Макет | Исходник КПК |
|---|---|
| `js/shell.js` | `5_Mission/INT_PDA/INT_PDA_Menu.c` |
| `js/pages/profile.js` | `INT_PDA_PageProfile.c` (и новости) |
| `js/pages/map.js` | `INT_PDA_PageMap.c` |
| `js/pages/chat.js` | `INT_PDA_PageChat.c` |
| `js/pages/faction.js` | `INT_PDA_PageFaction.c` |
| `js/pages/char.js` | `INT_PDA_PageChar.c` |
| `js/pages/auth.js` | `INT_PDA_PageAuth.c`, экран трофея из `INT_PDA_Menu.c` |
| `js/pages/admin.js` | `INT_PDA_PageAdmin.c`, `INT_PDA_PageAdminFactions.c` |
| `js/hud.js` | `INT_PDA_Hud.c` |
| `js/strings.js` | `stringtable.csv`, русская колонка |
| `js/data_real.js` | конфиг старого КПК, без паролей |
| `js/data.js` | состояние макета и придуманное наполнение |

## Отличия от игры

- Карта: сгенерированная заглушка `assets/map_placeholder.jpg`. Террейна РП-сервера здесь нет, в игре это `MapWidget`.
- Модель игрока: силуэт. В игре `PlayerPreviewWidget`.
- Анимации упрощены, звуков нет.
- Сервер имитируется: действия меняют только состояние страницы, после перезагрузки всё сбрасывается.
- Позиции кнопок UIF и ширины текста близки к игре, но шрифт рисует браузер, поэтому возможны расхождения на пару пикселей.

Правки макета записываем в `ПРАВКИ.md`: это список того, что потом делаем в моде.
