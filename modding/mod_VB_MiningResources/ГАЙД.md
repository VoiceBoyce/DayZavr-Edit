# VB_MiningResources — гайд

Своя замена купленного BRDK_GoldRush (руда, сервер 18). ТЗ: [ТЗ_VB_MiningResources.md](ТЗ_VB_MiningResources.md).
Механики перенесены 1:1, вместе с особенностями старого мода; проверки лицензии и внешних запросов нет.

## Состав

| Папка | Что |
|---|---|
| `VB_MiningResources/` | клиентский PBO: `config.cpp` (генерируется), `stringtable.csv` (генерируется), модели в `m\`, скрипты `scripts/4_World` |
| `VB_MiningResources_Server/` | серверный PBO (в `@Servermod\Addons`): настройки, результаты добычи и промывки, пресс, плавка |
| `@VB_MiningResources/`, `@VB_MiningResources_Server/` | собранные подписанные моды (`pbo.ps1 build`) |
| `настройки/settings.json` | настройки для сервера 18: `Instance_1\VB_Mods\VB_MiningResources\settings.json` |
| `tools/` | `import_assets.py` (перенос моделей, разово), `gen_config.py` (config.cpp + stringtable), `check_refs.py` (пути в моделях), `make_settings.py` (settings.json из GoldRush.json) |
| `старый мод/` | BRDK_GoldRush как образец, `_разбор/` — восстановленный код |

Правка предметов — в `tools/gen_config.py`, потом `python -I tools/gen_config.py` и `build`.

## Классы

`<Рес>` = Gold, Silver, Bronze, Iron, Titanium (металлы, плавятся в чаше) и Coal, Rubin, Nephrite, Sulfur (камни, прессуются).

| Что | Новый | Старый (наследник нового) |
|---|---|---|
| песок | `VB_MR_<Рес>_Sand` | `BRDK_<Рес>_Sand` |
| самородок / кусок | `VB_MR_<Рес>` | `BRDK_<Рес>` |
| слиток / брикет | `VB_MR_<Рес>_Bar` | `BRDK_Big<Рес>` |
| жила (объект карты) | `VB_MR_<Рес>_Vein` | `BRDK_<Рес>_Ore` |
| набор пресса / пресс / чаша | `VB_MR_Press_Kit` / `VB_MR_Press` / `VB_MR_MeltingBowl` | `BRDK_Press_kit` / `BRDK_Stone_Press` / `BRDK_MeltingBowl` |

- Старые классы: та же модель и название, в описании «Старый образец». Добыча и промывка выдают только новые,
  переработка старого даёт новое (поиск записи настроек: точное имя, потом `IsKindOf`).
- В крафтах DRL у компонентов с рудой `UseInheritance = 1` — старые засчитываются наравне с новыми.
- Слоты остались `BRDK_STONES` / `BRDK_METALS` (по ним в сохранении лежат вложения прессов и чаш).
- **Чаша в скриптах — `Cauldron`** (без своего класса): костёр пускает на треногу только тип ровно `Cauldron`
  (E83). Логика чаши — в `modded class Cauldron` под признаком `m_VB_MR_IsMeltingBowl`.
- Модели: пути внутри `.p3d` переписаны байтами `brdk_goldrush_client` → `vb_miningresources\m` (та же длина),
  поэтому всё лежит в подпапке `m`. Материалы `.rvmat` переведены в текст.

## Настройки (`settings.json`)

Поля те же, что в GoldRush.json (описание — `старый мод`… и `Instance_1\BRDK_MODS\инструкция для руд\ИНСТРУКЦИЯ.cpp` на 18):
`GoldInRiverSearchTime`, `MinCountInRiver`/`MaxCountInRiver`, `BadRiverBounty`, `MeltUpdatePeriod`, `MeltTempTreshold`,
`MineTools`, `VeineDataDataList`, `SandDataList`, `OreDataList`. Нет файла — создаётся с текущими значениями 18.

## Установка вместо BRDK_GoldRush

За один рестарт: убрать `@BRDK_GoldRush` и `BRDK_GoldRush_SERVER.pbo`, поставить `@VB_MiningResources` и
`VB_MiningResources_Server.pbo`, положить settings.json. **Не запускать сервер ни с одним из двух модов** — предметы
`BRDK_*` удалятся из сохранения. Ключ тот же DayZavrN.

## Проверено на стенде (2026-11-17)

- компиляция клиента и сервера, загрузка настроек;
- добыча киркой новой и старой жилы (время из настроек, самородки и камни к ногам, жила исчезает);
- пресс: полный стак крошки → кусок в хранилище пресса;
- промывка (серверная часть, на тестовой копии без воды): песок в сковороду;
- чаша встаёт на треногу костра;
- **переход старый мод → новый с тем же сохранением**: пресс и чаша со вложениями и грузом, слиток, брикет,
  набор — всё загрузилось новыми классами, ошибок нет.

Не проверено (руками): промывка у настоящей воды, плавка на огне (костёр на стенде не разгорелся), установка
набора пресса и разборка плоскогубцами, брикет угля в костре.

## Известное (оставлено как в старом моде, исправления — этап И2–И10 ТЗ)

- шанс промывки делится на число видов песка; результат пропадает, если в сковороде нет места;
- переработка только полного стака, без подсказки; прогресс сбрасывается рестартом;
- **чаша после первого остывания не плавит до рестарта** (флаг старта не сбрасывается) — И10;
- проверка воды через устаревший `CCTWaterSurface` (предупреждение при компиляции, работает).
