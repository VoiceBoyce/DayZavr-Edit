ИЗМЕНЕНИЯ RF В МОДЕ AI BANDITS (HunterZ)
Вносить заново в каждое обновление мода от автора.
Последний раз внесено: 16.10.2026, в версию мода под DayZ 1.30.

AI_Bandits_MoreHP.pbo (доп. HP и классы) НЕ трогать: это отдельный pbo, правки ниже его не касаются.
Правки вносятся только в AI_Bandits.pbo, в 2 файла:
  1) Scripts\4_World\classes\Managers\DynamicAIBManager.c  - свой расчёт лута у бандитов из групп
  2) Scripts\3_Game\DynamicAIBConfig.c                      - старые конфиги сами получают "cleanzerovector": 1

Быстрый путь: скрипт ..\_src_1.30\tools\merge_rf.py (рядом с папкой @AI Bandits) сам переносит обе правки
со старой сборки на новую. Если автор поменял код вокруг этих мест, скрипт остановится с ошибкой,
тогда вносить вручную по пунктам ниже.

1.1. В начало класса, сразу после строки
	protected static ref DynamicAIBManager Instance;
вставить блок:

	// MARK: - RF MODIFICATION -----------------------------------------------------

    private int minimumItemsToSpawn = 1;
    private int maximumItemsToSpawn = 3;

    private void rf_setupBandintLootListInside(BanditAI_Base banditAi, int locationId) {
		DynamicAIBConfig config = GetDayZGame().GetDynamicAIBConfig();
        TStringArray temporaryLootList = {};
        temporaryLootList.Copy(config.GroupLocations.Get(locationId).npcproperties.loot);

        Print(string.Format("[Info]: Размер временного массива: %1 (%2)", temporaryLootList.Count(), config.GroupLocations.Get(locationId).npcproperties.loot.Count()));

        TStringArray lootToSpawn = {};
        int minItems = minimumItemsToSpawn;
        int maxItems = maximumItemsToSpawn;
        if (temporaryLootList.Count() < maximumItemsToSpawn) { maxItems = temporaryLootList.Count(); }

        // RandomIntInclusive: from minItems to maxItems INCLUDING maxItems (1..3). Empty loot list -> 0 items.
        int randomAmount = 0;
        if (maxItems >= minItems) { randomAmount = Math.RandomIntInclusive(minItems, maxItems); }

        for (int i = 0; i < randomAmount; i++) {
            auto randomLootItem = temporaryLootList.GetRandomElement();
            if (!randomLootItem) {
                Print("[RF_Modding_BanditAi]-[Error] Объекта нет! Надо исправлять. Пытаемся отспавнить больше элементов чем в массиве");
                continue;
            }
            lootToSpawn.Insert(randomLootItem);
            temporaryLootList.RemoveItem(randomLootItem);
        }

        banditAi.SetupLoot(lootToSpawn);
    }

    // MARK: - END RF MODIFICATION -----------------------------------------------------

Количество предметов: от 1 до 3 включительно (Math.RandomIntInclusive).
Не менять обратно на Math.RandomInt(min, max): он НЕ включает max и даёт только 1-2.
Если у группы предметов в "loot" меньше 3, максимум = их число; если список пустой, лута нет.

======================================================================
2. Scripts\3_Game\DynamicAIBConfig.c
======================================================================

Зачем: с версии под 1.30 автор чистит объекты в точке 0 0 0 при старте только при "cleanzerovector": 1
в JSON-конфиге (раньше чистил всегда). Мод сам пересохраняет JSON при каждом старте, но старому конфигу
без этого поля пишет 0. Правка: при обновлении старого конфига (version меньше 3) ставить 1.
Новый конфиг, созданный с нуля, остаётся с 0 (как у автора). Дальше значение берётся из JSON,
и его можно поменять руками.

В LoadConfig(...) найти блок обновления конфига

		if (configData.version < 3)
		{
			configData.version = 3;
			configData.sniperDefensiveAggroSeconds = 30;
		}

и дописать 3 строки перед закрывающей скобкой:

		if (configData.version < 3)
		{
			configData.version = 3;
			configData.sniperDefensiveAggroSeconds = 30;
			// MARK: - RF MODIFICATION: old configs (before v3) always cleaned 0 0 0, keep that
			configData.cleanzerovector = true;
			// MARK: - END RF MODIFICATION
		}
